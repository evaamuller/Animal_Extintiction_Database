# Limitations and Future Work
1) Currently, our database focuses only on Australia. In the future, we want to extend it to include other countries as well, which is what our stakeholders said they would like to see, as suggested in their feedback on our pitch video.
2) We record populations only at the state level, which was done to unify the two chosen datasets. However, this introduces imprecision and loses some information. In the future, we would like to record populations at the level of regions.
3) Animal populations are hard to track because animals can move between locations. Moreover, animal populations are only estimates, and they can be tracked in different units. Currently, our database includes only animals whose populations were recorded as counts, as this is the only format our schema accepts. In the future, we would like to extend this to other formats, which would allow us to include a larger variety of animals. We would also like to store records of animal migration between locations, to correctly determine changes in population. This could also show whether changes in a particular location force animals to find a different habitat, which is something we do not record at the moment.
4) The real-world datasets were cleaned and checked for missing values and incorrect formatting, which should ensure that the inserted data is in normalized form. However, no explicit testing was conducted on the final cleaned data, which is something that needs to be addressed in the future.
